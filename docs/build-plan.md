# Build plan

## Decisions
- **Placeholder brand:** "Aavya Studio" (fictional). Every brand value lives in `brand.config.ts`.
- **Data:** mock JSON (`data/products.json`, generated by `scripts/seed.mjs`). All reads go through `lib/api.ts` so Shopify/Supabase can replace it later.
- **State:** Zustand with `persist` for cart, wishlist, currency and recently viewed.
- **Payments:** mock only. `lib/payments.ts` is the Razorpay integration point.
- **Fonts:** self-hosted via `@fontsource` (no runtime Google Fonts dependency).
- **Currency:** INR is the source of truth; USD is a display conversion labelled "approx." and checkout charges INR.
- **Checkout step 5 (brief was truncated):** Review & Place Order → `/order/[id]` confirmation.
